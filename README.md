# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3194 |
| 接口 | http://localhost:8194 |
| PostgreSQL | localhost:54394 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| printer | print123456 | 可送复核、可交班 |
| checker | check123456 | 只看，可翻交班快照 |

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 交班

交班清单页点「一键交班」，把当时所有待处理与领取中的编号、印张、机台冻结成一份只读快照；快照不提供修改或删除接口。历史快照与明细所有登录账号都能翻阅，只有印刷员能交班。

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮，也没有一键交班按钮。
4. 连送两条印张后立刻点一键交班，快照列出这两笔；等其中一条出结论后再打开该快照，仍显示交班当时的两笔及其当时状态。
