# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

印刷员交班时一键生成待处理清单快照：把当时所有待处理与领取中的印张（编号、印张、机台）抄进快照。快照只读，之后印张出结论也不影响快照内容。导航里的交班清单页可一键交班、翻历史快照、看快照明细。

## 启动

```bash
cd projects/15-print-register-review
docker compose up --build
```

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送复核按钮，也没有一键交班按钮，只能翻交班快照。
4. 有两笔待处理时到交班清单页点一键交班，快照列出这两笔（编号、印张、机台）。
5. 随后其中一笔出结论，再打开该快照，仍显示交班当时的两笔。
